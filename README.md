# ChatSync 🌐

Многофункциональный плагин для Minecraft-серверов, обеспечивающий продвинутую систему чата, личных сообщений, перевод системных сообщений о смерти и полную локализацию интерфейса.

---

## 📌 Основные возможности (Features)
* **Многоязычность (Localization):** Встроенная поддержка русского, английского, немецкого и французского языков (`ru`, `en`, `de`, `fr`).
* **Перевод событий:** Автоматический перевод сообщений о смерти (`death_messages_ru.json`) и названий сущностей (`entity_names_ru.json`).
* **Система личных сообщений:** Удобная приватная переписка между игроками.
* **Ролевой чат:** Команда `/me` — сообщения от третьего лица с поддержкой цветов.
* **Очистка чата:** Команда `/clear` — очистка чата для всех или для конкретного игрока, с подтверждением по клику.
* **Статистика чата:** Команда `/chatstats` — топ активных игроков и подробная статистика по каждому.
* **Объявления:** Команда `/broadcast` — серверные объявления с поддержкой звука, action bar и заголовков.
* **Асинхронные логи:** Весь чат (глобальный, локальный, ЛС, /me, объявления) пишется в файлы `logs/chat-YYYY-MM-DD.log` без нагрузки на основной поток.
* **Модерация и комфорт:** Списки игнорирования (`/ignore`) и режим скрытой прослушки (`/socialspy`).
* **Интеграции:** LuckPerms (плейсхолдеры префикса/суффикса напрямую через API, если нет PlaceholderAPI), CoreProtect (журналирование `/clear` для `/co lookup`), PlaceholderAPI, DiscordSRV — все опциональны (soft-depend).

## ⚙️ Команды и права (Commands & Permissions)

| Команда | Описание | Право (Permission) |
| :--- | :--- | :--- |
| `/chatsync reload` | Основная команда плагина | `chatsync.admin` |
| `/msg <игрок> <текст>` | Отправить личное сообщение | `chatsync.msg` |
| `/reply <текст>` | Быстрый ответ на последнее сообщение | `chatsync.msg` |
| `/ignore <игрок>` | Добавить игрока в игнор-лист | `chatsync.ignore` |
| `/ignorelist` | Просмотреть список игнорируемых | `chatsync.ignore` |
| `/socialspy` | Включить режим прослушки чата | `chatsync.socialspy` |
| `/me <действие>` | Сообщение от третьего лица | `chatsync.me` |
| `/clear [игрок]` | Очистить чат (себе или указанному игроку), запрашивает подтверждение | `chatsync.clear` |
| `/chatstats [игрок]` | Топ по активности или статистика конкретного игрока | `chatsync.chatstats` (свои), `chatsync.chatstats.others` (чужие) |
| `/broadcast <текст>` | Отправить объявление всем игрокам | `chatsync.broadcast` |

Права и форматы всех новых команд можно переопределить в `config.yml` без пересборки плагина.

### Как работает `/clear`
1. `/clear` — очистить чат всем, или `/clear <игрок>` — очистить чат конкретному игроку.
2. Плагин пришлёт кликабельное сообщение-подтверждение (истекает через `clear.confirm_timeout` секунд из `config.yml`).
3. Нажмите на сообщение или введите `/clear confirm` (или `/clear <игрок> confirm`), чтобы подтвердить очистку.

### Как работает `/chatstats`
* `/chatstats` — показывает топ активных игроков (размер топа настраивается в `stats.top_size`).
* `/chatstats <игрок>` — показывает подробную статистику (глобальный чат / локальный чат / ЛС / /me / всего) для указанного игрока. Просмотр чужой статистики требует права `chatsync.chatstats.others`.

## 🚀 Установка (Installation)

1. Скачайте `.jar` файл плагина.
2. Поместите его в папку `plugins` вашего Minecraft-сервера (поддерживаются ядра Spigot, Paper).
3. Запустите или перезапустите сервер для генерации файлов конфигурации.
4. Отредактируйте `config.yml` и языковые файлы по своему усмотрению — каждый параметр в `config.yml` сопровождается двуязычным комментарием (`# [EN] ...` / `# [RU] ...`).
5. (Опционально) Установите LuckPerms и/или CoreProtect — плагин автоматически подключит интеграции, если их обнаружит.

## 🛠️ Сборка из исходников (Building from Source)

Для сборки проекта на вашем компьютере требуются **Java 17+** и **Maven**:

```bash
git clone https://github.com/Mutya660/ChatSync.git
cd ChatSync
mvn clean package
```
